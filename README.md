# Espaço de trabalho do Codex

Este repositório é um espaço de trabalho para usar o Codex no ChatGPT.

Você pode pedir ao Codex para criar, editar, explicar e testar projetos aqui. Quando decidir o que deseja construir, descreva a ideia no chat; o projeto e as instruções de desenvolvimento poderão ser adicionados a este repositório.
